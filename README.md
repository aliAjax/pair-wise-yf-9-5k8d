# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

## 扩展包

- 每款游戏可登记扩展包，填写最少人数、最多人数和增加时长，可单独启用或停用。
- 启用多个扩展时，支持人数取交集，时长按增加最多的一项叠加到基础版。
- 只有当前筛选人数落在交集内才算适配，收藏列表、详情状态和顶部统计同步更新。
- 停用的扩展仍显示在详情里，但不再参与计算。
- 扩展包"不再使用"时，它带来的规则会留在基础版的"待归类"里，可以再归入具体分类，不会被直接丢掉。

## 代码结构

- `expansion-data.js`：扩展包资料层，负责创建、旧存档迁移和退役（规则转入待归类）。
- `expansion-core.js`：计算规则层，纯函数实现人数交集、时长叠加、适配判断和规则统计。
- `app.js`：页面接入层，负责渲染和交互。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。数据只保存在本机 localStorage。
