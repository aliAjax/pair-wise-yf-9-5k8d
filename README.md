# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

## 扩展包

- 每款游戏可登记多个扩展包，填写最少人数、最多人数和增加时长，可单独启用或停用。
- 启用多个扩展时，支持人数取基础版与所有启用扩展的交集；时长只叠加启用扩展中"增加最多"的那一项。
- 顶部人数筛选即"当前人数"，落在交集内才算适配：收藏列表按交集过滤，详情显示适配状态，顶部统计同步显示适配款数。
- 停用的扩展仍显示在详情里，但不再参与人数、时长和规则统计。
- 移除扩展时，它带来的规则留在基础版的"待归类"里，可手动归入四类规则卡片，不会直接丢失。

## 代码结构

- `expansion-data.js`：扩展资料与本地存储（默认数据、旧数据迁移、localStorage 读写）。
- `expansion-calc.js`：计算规则（人数交集、时长叠加、适配判断、扩展移除时的规则保留），纯函数。
- `app.js`：页面接入（渲染与事件）。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。所有数据只保存在本机 localStorage。
